# Jersey Texture Templates

Lightweight SVG jersey textures for the AR team customization flow.

These assets use stable file names for all 12 scanner targets. The current
templates avoid large text, crests, and high-detail center marks so the designs
stay readable when the model UVs split the texture across the jacket, sleeves,
and back.

They are still intended to be iterated visually on mobile, but they now represent
the base pattern strategy for the AR jersey texture pipeline.

`jersey-uv-layout.svg` is the exported layout reference for the current
`public/models/model.glb` jersey mesh. Use it as a visual guide when refining
team-specific jersey artwork.
